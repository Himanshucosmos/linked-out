# LinkedOut

> They thought LinkedIn was Tinder. This is your response.

Paste a harasser's LinkedIn profile and the DM they sent. Get a savage, copy-ready callout post — powered by AI, ready to publish in seconds.

---

## Run it locally

```bash
git clone https://github.com/Himanshucosmos/linked-out.git
cd linked-out
npm install
```

Add a `.env.local` file:

```env
GROQ_API_KEY=your_key_here  # free at console.groq.com
```

```bash
npm run dev
```
